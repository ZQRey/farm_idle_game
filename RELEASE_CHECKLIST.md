# Farm Idle Companion — 1.0.0-rc.1 Release Checklist

## Windows desktop smoke

- [ ] Запустить FarmIdleCompanion.exe двойным кликом.
- [ ] Игра не появляется отдельной кнопкой на taskbar.
- [ ] В системном трее видна иконка трактора.
- [ ] ЛКМ по tray открывает «Штаб фермы».
- [ ] ПКМ по tray открывает контекстное меню.
- [ ] Полоса игры находится непосредственно над taskbar.
- [ ] Обычные клики по рабочему столу проходят сквозь полосу к ярлыкам.
- [ ] Игра не перехватывает keyboard focus.
- [ ] Открытие HQ не ломает click-through основной полосы.
- [ ] После закрытия HQ основной companion продолжает работать.

## Window / Z-order

- [ ] Companion не перекрывает обычные приложения поверх них.
- [ ] Desktop icons остаются видимыми и кликабельными.
- [ ] Полоса не уходит под taskbar.
- [ ] После Explorer restart / taskbar restart позиция остаётся приемлемой.
- [ ] Pause/Resume через tray работает.
- [ ] Exit через tray полностью завершает процесс.

## Multi-monitor

- [ ] Переключение на Monitor 1.
- [ ] Переключение на Monitor 2.
- [ ] Возврат на primary monitor.
- [ ] При одинаковой нижней границе работает «Все мониторы».
- [ ] При разноуровневой раскладке «Все мониторы» недоступен.
- [ ] После смены monitor geometry поле корректно пересчитывает ширину.
- [ ] После перезапуска выбранный monitor восстанавливается.

## Save / restart

- [ ] Сделать несколько покупок и дождаться autosave.
- [ ] Закрыть игру через tray и запустить снова.
- [ ] Деньги, культура, техника, worker/building state восстановились.
- [ ] Прогресс поля восстановился без визуальных артефактов.
- [ ] Повредить копию settings.cfg в тестовом профиле и проверить backup recovery.

## Visual / animation

- [ ] Трактор движется плавно.
- [ ] Работники анимируются без рывков.
- [ ] Рост растений визуально соответствует фазе.
- [ ] Комбайн и грузовик корректно появляются/исчезают.
- [ ] Дождь/град/снег/ночь визуально читаются.
- [ ] Windmill/tree/crop custom animations выглядят приемлемо на 12 FPS.
- [ ] На 125%/150% Windows DPI нет критичных смещений HQ/tray UI.

## Release gate

Для 1.0.0 должны быть выполнены:
- [ ] GitHub CI полностью зелёный.
- [ ] Windows executable smoke зелёный.
- [ ] Все пункты Windows desktop smoke выше проверены.
- [ ] Multi-monitor проверен хотя бы на двух физических дисплеях.
- [ ] Нет blocker/critical багов.
